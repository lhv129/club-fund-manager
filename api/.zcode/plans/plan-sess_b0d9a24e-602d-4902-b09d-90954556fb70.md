## Kế hoạch: Hoàn thiện 5 API Dashboard còn lại

Dựa trên mock data `ClubDashboardData`, cần tạo 5 endpoint mới. Cấu trúc mỗi endpoint: Controller → Service (resolvePeriod) → Repository (query) → Resource (transform).

---

### Endpoint 1: `GET /dashboard/contributions` — **Paginated**

**Mock response fields:** `{ id, period_id, amount, status, user: { id, fullname } }`

**Flow:**
1. `resolvePeriod` → `date_from`/`date_to`
2. Tìm `FundPeriod` có `year`/`month` nằm trong date range
3. Query `monthly_contributions` cho các period_id đó, eager load `user:id,fullname`
4. Paginate → `paginateResponse`

**Repository**注入 thêm `MonthlyContribution` model.

**Resource mới:** `ContributionDashboardResource`

---

### Endpoint 2: `GET /dashboard/sessions` — **Paginated**

**Mock response fields:** `{ id, session_date, court_name, court_address, start_time, end_time, status, type, player_count, total_amount, amount_per_player }`

**Flow:**
1. `resolvePeriod` → `date_from`/`date_to`
2. Query `exchange_sessions` where `session_date` BETWEEN date_from/date_to
3. Paginate → `paginateResponse`

**Repository**注入 thêm `ExchangeSession` model.

**Resource mới:** `SessionDashboardResource`

---

### Endpoint 3: `GET /dashboard/transactions` — **Paginated**

**Mock response fields:** `{ id, type, source, amount, description, reference_code, transaction_date, sender_name }`

**Flow:**
1. `resolvePeriod` → `date_from`/`date_to`
2. Query `transactions` where `transaction_date` BETWEEN date_from/date_to
3. Paginate → `paginateResponse`

**Repository**注入 thêm `Transaction` model.

**Resource mới:** `TransactionDashboardResource`

---

### Endpoint 4: `GET /dashboard/cashFlow` — **Aggregated (no pagination)**

**Mock response fields:** `[{ date, label, income, expense, net }]`

**Flow:**
1. `resolvePeriod` → `date_from`/`date_to`
2. `SELECT DATE(transaction_date) as date, SUM(CASE type='income' THEN amount ELSE 0 END) as income, SUM(CASE type='expense' THEN amount ELSE 0 END) as expense` từ `transactions`
3. `WHERE transaction_date BETWEEN date_from AND date_to` + `club_id`
4. `GROUP BY DATE(transaction_date) ORDER BY date ASC`
5. Tính `net = income - expense`, `label = date->format('d/m')`
6. `responseCommon`

**Không cần Resource** — trả về plain array từ repository.

---

### Endpoint 5: `GET /dashboard/activity` — **Aggregated (no pagination)**

**Mock response fields:** `[{ date, label, male, female, groups, total }]`

**Flow:**
1. `resolvePeriod` → `date_from`/`date_to`
2. JOIN `exchange_session_players` → `exchange_sessions` ON `exchange_session_id`
3. `SELECT session_date as date, SUM(esp.male) as male, SUM(esp.female) as female, COUNT(DISTINCT esp.exchange_session_id) as groups`
4. `WHERE session_date BETWEEN date_from AND date_to` + `club_id`
5. `GROUP BY session_date ORDER BY date ASC`
6. Tính `total = male + female`, `label = date->format('d/m')`
7. `responseCommon`

**Không cần Resource** — trả về plain array.
